# Reno Rangers Full-Funnel SEO + Conversion Plan

This overlay expands the weekly SEO agent from "two keywords" into a complete organic lead-generation system.

## Primary business outcome
The real outcome is not rankings or traffic by themselves. The outcome is more qualified renovation enquiries and more completed forms from people who fit Reno Rangers' verified services and service area.

Ranking KPIs remain useful leading indicators, but weekly decisions must optimize for:
1. qualified organic leads,
2. completed contact/offerte forms,
3. strong commercial visibility across the renovation journey,
4. trust and clarity that help a visitor choose Reno Rangers,
5. architect/interior-designer partnership enquiries.

Never invent conversion numbers when analytics do not provide them.

## Whole-market coverage map
Every run must review the whole opportunity map, not only two keyword phrases.

Maintain active coverage across:
- direct commercial: renovatiebedrijf, aannemer renovatie, totaalrenovatie, badkamerrenovatie, binnenafwerking;
- local intent: Antwerpen + verified nearby service area;
- project type: woning, appartement, verhuur/investment, bathroom, interior finishing;
- decision intent: aannemer kiezen, offerte vergelijken, renovatie stappenplan, planning/coordinatie;
- problem intent: outdated interior, poor layout, small bathroom, property needing modernization;
- proof/trust intent: project examples, process, what is included, communication, planning, workmanship;
- B2B: architects, interior architects and designers needing an execution partner.

For every material search-intent gap, decide one of:
- existing page can serve it -> improve that page;
- another page is cannibalizing it -> resolve the conflict;
- internal authority is weak -> add relevant contextual links;
- distinct intent needs a new page -> prepare NEEDS APPROVAL;
- demand/business fit is too weak -> do not create content.

Do not leave a valuable gap unaddressed merely because the week's current two target keywords are different.

## Weekly sprint structure
Each sprint should normally contain:
1. one primary commercial ranking move,
2. one conversion-quality improvement on the same user journey when evidence supports it,
3. one supporting authority/internal-link/content-gap action when safe.

The work may touch multiple related existing pages when allowed by policy and when the changes form one coherent customer journey. Do not make unrelated bulk edits.

## Conversion-first content standard
SEO text must read like useful sales guidance written for a real homeowner, not text written for Google.

Every important commercial page should, where relevant and factually supported:
- state clearly who the service is for and what problem it solves;
- explain the actual scope/process in plain Dutch;
- answer the questions a serious buyer asks before requesting a quote;
- make the difference between Reno Rangers and a generic list of contractors understandable without unsupported claims;
- reduce uncertainty about planning, coordination, contact and next steps;
- use project examples already verified in the repository when relevant;
- include a clear, natural CTA to request a visit/quote;
- avoid keyword stuffing, repetitive city names, generic filler and AI-sounding paragraphs.

Useful copy beats longer copy. A paragraph that does not help ranking intent, trust, understanding or conversion should not be added.

## Form-conversion review
On the page selected for a sprint, review the path to the form/contact action:
- CTA clarity and placement,
- whether the user knows what happens after submitting,
- whether unnecessary friction/confusion exists,
- whether the page gives enough trust and project-fit information before asking for contact,
- whether mobile users have a clear next action.

Small safe CTA/copy improvements on existing pages may be included only when allowed by automation policy. Larger UX/form changes require approval.

## Gap register
Every weekly GitHub issue must include a short "Coverage gaps" section with:
- highest-value unfilled commercial gap,
- highest-value decision/problem gap,
- highest-value conversion/trust gap,
- whether each gap is EXECUTE NOW, NEEDS APPROVAL, MONITOR, or NOT RELEVANT.

This prevents the program from repeatedly optimizing the same two phrases while other valuable gaps remain open.

## Quality bar
Do not publish low-value SEO copy just to increase word count.
Do not create pages with near-duplicate intent.
Do not invent prices, savings, timelines, guarantees, capacities, reviews or project facts.
Do not broaden the service area beyond verified scope.
Every change must have a ranking hypothesis, conversion hypothesis, or both.
