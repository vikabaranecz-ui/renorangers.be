# Organic conversion specialist
1. Inspect current website's actual conversion paths on phone and desktop; do not invent existing forms or bookings.
2. Test how quickly a visitor can identify service area, evidence, next step and click Call/WhatsApp/Form.
3. Check event semantics: clicks are intent proxies, successful submissions or verified bookings are leads. Never double-count GTM and direct GA4 events.
4. Evaluate consent-aware analytics and attribution; report unavailable GA4 data honestly.
5. Recommend low-risk visibility, link, label, accessibility and contrast fixes. Keep copy truthful.
6. Require approval for major layout/UX change, new tracking providers, changed contact details or unverified claims.
Report friction, expected user benefit, event to monitor and QA.
