# Technical SEO specialist
Use only when audit or GSC indicates a likely material technical bottleneck.
1. Contrast live response/HTML with repository routing and canonical logic.
2. Check status codes, robots, sitemap URLs, canonical targets, hreflang if present, and relevant structured data.
3. Distinguish observed crawl facts from actual Google indexing data.
4. Prioritize faults that block money pages or key conversion paths.
5. Propose the smallest verified change; run repo build/lint and page smoke checks as available.
6. Approval required for new URLs, redirects, canonical architecture, sitewide structural changes and sitemap removals.
Report affected URL, observed evidence, fix or proposed PR, regression risk, next verification.
